# PhoneMic — телефон как микрофон для Windows 11

PhoneMic превращает Android-телефон в системный микрофон Windows: Zoom, Discord, OBS и любые
другие приложения видят устройство **«PhoneMic Virtual Microphone»** через собственный
аудиодрайвер. Передача — зашифрованная (TLS + токен + AES-256-GCM), по любому из четырёх
транспортов: **Wi-Fi, USB, Wi-Fi Direct, Bluetooth**. Целевая задержка — **< 50 мс** (пресет
«Ультра»), комфортный режим 50–100 мс включён по умолчанию.

```
┌─────────────────┐   Opus/PCM  (UDP+AESGCM / TCP-TLS / RFCOMM)   ┌──────────────────────┐
│  Android 12+    │ ────────────────────────────────────────────▶ │  Windows 11          │
│  PhoneMic app   │   Control: TLS + HMAC-токен (+ команды)       │  PhoneMic (WinUI 3)  │
│  AudioRecord    │ ◀──────────────────────────────────────────── │  джиттер → декодер   │
│  MediaCodec     │                                               │        │ IOCTL (PCM) │
└─────────────────┘                                               │        ▼             │
                                                                  │  phonemic.sys        │
  Регулировка громкости/мьют/вкл-выкл — с телефона                │  PortCls/WaveRT      │
                                                                  └──────────┬───────────┘
                                                                             ▼
                                                          Zoom / Discord / OBS / ... ◀──
```

## Возможности

- **Транспорты** (переключаются в UI): Wi-Fi LAN · USB (модем/tethering через NCM или `adb reverse`) · Wi-Fi Direct (ПК — Group Owner, телефон подключается к группе) · Bluetooth RFCOMM (ПК подключается к телефону после сопряжения).
- **Кодеки**: Opus 24–128 kbps (MediaCodec на телефоне, Concentus на ПК) и PCM 16-bit/48 кГц без потерь (для быстрых сетей).
- **Безопасность**: TLS 1.2/1.3 с самоподписанным сертификатом + TOFU-пиннинг SHA-256 отпечатка; авторизация по 32-байтному токену (HMAC-челлендж); медиа — AES-256-GCM с HKDF-ключами и replay-защитой; BT — шифрование канала Bluetooth + AES-GCM для control.
- **Расширенный UI**: порты control/media, медиа-режим (UDP/TCP/авто), кодек/битрейт/кадр, пресеты джиттер-буфера (Ультра/Баланс/Стабильный), тестовый сигнал 440 Гц, статус драйвера с счётчиками, журнал.
- **Управление с телефона**: громкость (0–150 %), мьют, полное включение/выключение;Foreground Service с уведомлением и кнопками.
- **Адаптация**: адаптивный джиттер-буфер, PLC (Opus concealment), автопереподключение, `busy`-защита от второго клиента.

## Быстрый старт

### 1. Соберите приложения

Вариант **CI (проще всего)**: залейте репозиторий на GitHub — workflows `android` и `windows`
соберут `PhoneMic-android.apk` и `PhoneMic-win-x64.zip` в артефактах.

Вариант **локально**:

```bash
# Android (JDK 17 + Android SDK):
cd android-app && gradle wrapper --gradle-version 8.9 && ./gradlew :app:assembleRelease -PciSigning

# Windows (.NET 8 SDK):
dotnet publish windows-app/src/PhoneMic.App/PhoneMic.App.csproj -c Release -r win-x64 --self-contained -p:Platform=x64
```

### 2. Соберите и установите драйвер

```powershell
# сборка (VS2022 + WDK 10.0.22621+): см. docs/DRIVER_BUILD.md
msbuild driver\phonemic.vcxproj /p:Configuration=Release /p:Platform=x64

# включить тестовую подпись (один раз, от администратора) и перезагрузиться:
bcdedit /set testsigning on

# установка:
powershell -ExecutionPolicy Bypass -File scripts\install_driver.ps1
```

### 3. Первый запуск

1. Запустите **PhoneMic.exe** — на странице «Безопасность» покажите телефону **токен** (кнопка «Показать») и **отпечаток сертификата**.
2. В приложении на телефоне: выберите транспорт → «Искать ПК» (или введите IP вручную) → вставьте токен → **«Включить микрофон»**.
3. Подтвердите отпечаток сертификата (должен совпадать с показанным на ПК).
4. Проверьте тракт: страница «Аудио» → включите **тестовый сигнал** и убедитесь, что полоса «PhoneMic Virtual Microphone» двигается в настройках звука Windows. Выберите этот микрофон в Zoom/Discord/OBS.
5. Отключите тестовый сигнал — микрофон в эфире.

## Транспорты: тонкости

| Транспорт | Как включить |
|---|---|
| Wi-Fi | ПК и телефон в одной сети. Телефон ищет ПК кнопкой «Искать ПК» (UDP-broadcast). |
| USB (просто) | На телефоне включите «USB-модем» (tethering). Windows 11 поднимет NCM-сеть автоматически; телефон сам найдёт ПК по шлюзу. |
| USB (adb) | USB-отладка на телефоне + на ПК «Транспорт → Настроить adb reverse». Телефон подключится к 127.0.0.1 автоматически. |
| Wi-Fi Direct | ПК: «Транспорт → Включить публикацию». Телефон: транспорт «Wi-Fi Direct» → включить микрофон → телефон подключится к группе `DIRECT-…` (пароль показывается на ПК). |
| Bluetooth | Сопрягите телефон с ПК. Телефон: транспорт «Bluetooth» → «Включить». ПК: «Подключение → Обновить → Подключиться». |

## Задержка

| Пресет | Джиттер-цель | Реально (PCM/Wi-Fi) | Реально (Opus 20 мс) |
|---|---|---|---|
| Ультра | 30 мс | ~35–45 мс | ~55–70 мс |
| Баланс | 40 мс | ~50–60 мс | ~70–90 мс |
| Стабильный | 80 мс | ~90–110 мс | ~110–140 мс |

Советы: PCM + Wi-Fi 5 ГГц + «Ультра» → устойчивые <50 мс. Bluetooth — только Opus ≤64 kbps (пропускная способность RFCOMM ограничена).

## Известные ограничения v1.0

- Драйвер требует **тестовой подписи** или attestation-подписи Microsoft (бесплатно через Partner Center при наличии EV-сертификата организации) — см. `docs/DRIVER_BUILD.md`.
- Сигнатуры `IMiniportWaveRTStreamNotification` в разных WDK немного различаются — точки правки вынесены в один блок `AllocateWaveRtBuffer` (см. build-заметки).
- Переключение транспорта требует переподключения (нет горячего роуминга).
- Мониторинг собственного звука (сквозной мониторинг в наушники телефона) не реализован.
